# 0.1.0 验证记录

日期：2026-10-22。用户本轮明确暂不进行实机连接，所有网络协议测试均使用本地模拟服务。

## Wi-Fi 认证失败接续修复（2026-10-22）

- 用户截图显示系统要求相机 WPA2 密码；日志显示蓝牙配对与凭据读取成功，Wi-Fi 认证失败，没有足够证据断言密码本身错误。
- 自动认证失败改为等待接续，保留蓝牙及设备标识；手动加入后不重新配对。素材握手失败也保留当前网络，直到主动取消或断开。
- 使用可读取的 SSID 和 Wi-Fi 网卡 IPv4 地址验证就绪，替代固定等待 1.5 秒；旧网段、自分配地址及其他 SSID 不能被视为就绪。
- 校验蓝牙凭据响应格式，移除末尾 NUL 终止符、保留合法空格，并拒绝异常长度和嵌入 NUL。
- 自动连接选择同名热点中信号最强的扫描结果；蓝牙凭据读取间隔与参考实现对齐。
- 新增模拟测试：认证失败保留蓝牙、手动接续复用设备身份、素材失败保留网络、DHCP 失败不提前握手、取消时只清理一次，以及凭据解析和网卡地址判断。
- 上述是客户端流程修复与本地验证；真实 macOS 自动认证失败的具体原因仍需新构建记录的系统错误码确认，不能将测试通过当作实机认证已修复。
- 等待接续的界面已使用显式测试夹具验证：不再显示新扫描入口；显示相机密码查看路径和继续/取消按钮；点击继续后可完成模拟连接并回到素材页。

## 已知边界

- 社区协议可能随固件变化，BLE/UDP 时序和分页需要实机调整。
- 手动 Wi-Fi 会话没有稳定相机标识，为防不同相机素材混写，不支持跨会话自动续传。
- HTTP 源端没有可用哈希时只能核验长度和本地指纹，不能宣称源端哈希核验。
- 目前是本机架构构建及临时签名，不是面向公众发布的安装包。
- macOS Wi-Fi/蓝牙权限和恢复网络功能尚未实机验收。
