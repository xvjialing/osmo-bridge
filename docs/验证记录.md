## Logo 接入验证（2026-10-22）

- 矢量源：`assets/brand/logo.svg`；脚本生成 PNG、10 个 iconset 尺寸、ICNS、应用内标识和 favicon。
- 16、32、64、96px 在浅色/深色背景上检查轮廓；源 PNG 为 1024px RGBA，保留透明外边距。
- 开发构建和 production 构建均通过，逐字节确认两种二进制内嵌同一 PNG。
- `.app` 的 `CFBundleIconFile` 指向 `Resources/appicon.icns`，资源一致性与签名验证通过。
- 打包应用成功启动，应用内新标识渲染正确。
- 当前工具无法读取 Dock 窗口；沙盒内 dev GUI 启动遇到 WebKit/Launch Services 权限限制，已停止该检查。未声称完成 dev 和 Dock 的视觉验收。
- `main.go` 的 Wails `Options.Icon` 在应用启动时调用 macOS `setApplicationIconImage`，并使用 `ActivationPolicyRegular`。用户正常终端运行 dev 时使用这条同一初始化路径。

## 已验证

- Go 固定 DUML 报文 CRC、分片、噪声与错误校验和处理。
- Action 6 风格清单记录边界、自定义文件名、照片/视频元数据和双存储 ID。
- 本地 UDP 模拟相机：握手、回放状态位确认、内置存储和 SD 卡清单获取。
- HTTP 原始字节与 SHA-256 一致；暂停续传；服务端忽略 Range 时安全重下。
- 错误 Content-Range、截断响应、HTTP 重定向不产生完成文件。
- 已有目标文件不覆盖；符号链接不能越出用户选择的下载目录。
- 应用重启将未完成任务恢复为暂停，不自动继续传输；状态快照不共享可变切片。
- `go test -race ./...`、`go vet ./...` 通过。
- React/TypeScript 类型检查和 Vite 生产构建通过。
- 使用 shadcn CLI 生成共享组件；前端静态规范审计零错误。
- DESIGN.md 官方 lint 零错误，存在仅用于说明的未引用 token 警告。
- 原生 `.app` 成功启动，Wails 服务返回真实默认导入目录，未触发蓝牙扫描或相机连接。
- 应用内浏览器：未连接、空相册、虚拟素材、文件名搜索、视频筛选、单项选择、加入队列、暂停、恢复入口、权限错误提示、弹窗关闭与焦点恢复。
- 820px iframe 窄窗口渲染检查：侧栏与双列素材布局正常，队列按设计移动到素材区下方。

## 已知边界

- 社区协议可能随固件变化，BLE/UDP 时序和分页需要实机调整。
- 手动 Wi-Fi 会话没有稳定相机标识，为防不同相机素材混写，不支持跨会话自动续传。
- HTTP 源端没有可用哈希时只能核验长度和本地指纹，不能宣称源端哈希核验。
- 目前是本机架构构建及临时签名，不是面向公众发布的安装包。
- macOS Wi-Fi/蓝牙权限和恢复网络功能尚未实机验收。
